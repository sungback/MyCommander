# PPTX 빠른 미리보기 개선 계획

- 작성일: 2026-10-18
- 기준 커밋: `4caac0c` (1.2.61)
- 목표: Space로 연 Quick Preview에서 PPTX를 실제 슬라이드 모양(위치·도형·이미지·서식 있는 텍스트)으로 보여 주고, PDF 미리보기와 같은 방식(왼쪽 썸네일, ↑↓로 한 장씩)으로 넘긴다.

## 현재 구현
- `quickPreviewRenderers/pptxRenderer.ts`가 `ppt/slides/slideN.xml`에서 `<a:t>` 텍스트만 뽑아 슬라이드별 카드로 나열한 HTML을 만들고, 샌드박스 `<iframe srcDoc>`로 보여 준다.
- 위치·도형·이미지·표·배경·서식은 표시하지 않는다. 최대 100장까지만 보여 준다.
- 파일은 `read_file_binary`(최대 20 MB)로 읽는다. 이미지가 많은 강의 자료는 20 MB를 넘을 수 있다(로컬 예: 20.3 MB 파일 있음).

## 방식 비교
| 방식 | 재현도 | 비용·위험 | 판단 |
|---|---|---|---|
| **pptxtojson으로 해석 + 직접 그리기 (추천)** | 저자 기준 일반 문서 80~95% | MIT, 2.2.0(2026-09 갱신, npm 레지스트리 2026-10-18 확인). 의존성 jszip(이미 사용)·txml·tinycolor2(모두 MIT). 그리는 코드는 우리가 작성 | 해석 결과(JSON)가 명확하고 유지 중. 화면은 PDF 뷰어 구조를 재사용 |
| pptx-preview로 바로 그리기 | 비슷하거나 높을 수 있음 | ISC 1.0.7(2025-10), 저장소 정보 없음, echarts 등 큰 의존성. 앱 DOM에 직접 그림 | 유지 상태와 보안 경계가 불확실 |
| LibreOffice로 PDF 변환 후 PDF 뷰어 사용 | 가장 높음 | 사용자 PC에 설치되어 있어야 함(이 Mac에는 없음), 변환이 느림 | 선택 기능 후보로만 남김 |
| Keynote·PowerPoint 자동화로 내보내기 | 높음 | 앱 실행 필요, 미리보기로 부적합 | 제외 |

## 화면과 조작
- PDF 미리보기와 같다: 왼쪽 슬라이드 썸네일, 오른쪽 현재 슬라이드 한 장(창에 맞춤), `3 / 24` 표시.
- 키: `↓`·`→`·`PageDown` 다음, `↑`·`←`·`PageUp` 이전, `Home`·`End` 처음·끝, `Space`·`Esc` 닫기.
- 지금의 텍스트 목록 보기는 "텍스트 보기"로 남긴다(해석 실패 시 대체 화면 겸용).

## 보안 경계
- pptxtojson이 만드는 텍스트 HTML은 파일 내용에서 나오므로 신뢰하지 않는다.
- 슬라이드는 지금처럼 스크립트를 허용하지 않는 샌드박스 `<iframe srcDoc>` 안에 그린다. 앱 DOM에 직접 넣지 않는다.
- 이미지는 `blob` 모드로 받아 객체 URL을 한 번만 만들고, 슬라이드·썸네일 HTML은 그 URL을 참조한다(base64를 슬라이드마다 복제하지 않음). 미리보기를 닫으면 URL을 모두 해제한다. CSP `img-src`는 이미 `blob:`을 허용한다.

#### 0단계 결과
- 로컬 PPTX 694개: 중앙값 0.7 MB, 20 MB 초과 36개(5%), 최대 230.7 MB. asset URL 읽기(20 MB 한도 없음)가 필요하다.
- 해석 성공 16/17. 슬라이드 2,156장, 해석 시간 최대 0.8초(230.7 MB, 270장), 597장 자료 0.5초. 웹뷰에서는 다를 수 있다.
- 실패 1건: XML 네임스페이스 접두어(`ns0:`)로 저장된 파일(Python ElementTree로 수정된 파일). pptxtojson이 접두어 없는 이름만 찾는다. 로컬 468개 중 2개(0.4%)라 1차에서는 텍스트 보기로 대신한다.
- 요소 구성: 도형 6,217 / 텍스트 4,274 / 이미지 3,387 / 그룹 280(최대 깊이 3) / 표 50 / 차트 1. SmartArt·수식·동영상은 표본에 없었다.
- 도형 6,217개 모두 SVG 경로(`path`, `pathViewBox`)가 있다. 모양별 CSS 매핑 없이 SVG 하나로 그릴 수 있다.
- 채우기: 색 2,078 / 그라데이션 33 / 이미지 20. 슬라이드 배경: 색 2,115 / 이미지 41.
- 발표자 노트가 있는 슬라이드 555장(26%). 후속 기능 후보로 가치가 있다.
- 텍스트 HTML은 인라인 스타일로 글꼴을 지정한다(예: `font-family: NanumGothic`). 설치되지 않은 글꼴은 `@font-face`의 `local()` 별칭으로 Apple SD Gothic Neo·맑은 고딕에 연결한다.
- 텍스트 본문은 pptxtojson이 HTML 이스케이프하지만 모든 속성 경로가 이스케이프되는지는 확인하지 못했다. 샌드박스 iframe 경계를 유지한다.
- 메모리: Node 프로세스 RSS가 230.7 MB 자료 후 약 830 MB까지 늘었다(누적). 아주 큰 자료는 웹뷰 메모리를 많이 쓴다. 1차는 제한 없이 두고 실제 앱에서 확인한다.

### 1. 문서 읽기와 모델
- [x] asset URL로 읽고(20 MB 한도 없음), 실패하면 `read_file_binary`로 읽는다(PDF와 같은 순서). 미리보기 핸들러는 `{ type: "pptx", src }`만 돌려주고 해석은 화면이 맡는다(로더의 `loadPptxRenderer` 옵션은 쓰이지 않게 되어 제거).
- [x] `pptxDeck.ts`: pptxtojson을 지연 로드해 해석하고(`imageMode: "blob"`), pptxtojson이 만든 이미지 객체 URL을 모아 `dispose()`로 해제한다. 노트는 이번 범위 밖이라 쓰지 않는다.
- [x] 다른 파일로 바뀌거나 닫으면 해석 결과를 버리고 URL을 해제한다.

### 2. 슬라이드 HTML 만들기 (순수 함수)
- [x] `buildSlideDocument(slide, size)`: pt 단위 좌표로 요소를 절대 배치한다(배열 순서가 아니라 `order` 순으로 겹침).
  - 텍스트·도형: 위치, 크기, 회전·뒤집기, 채우기(색·그라데이션·이미지), 테두리, 세로 정렬, 여백, 자동 맞춤 글자 배율
  - 도형 모양: 해석 결과의 SVG 경로로 그린다(표본 6,217개 모두 경로 있음). 경로가 없으면 사각형으로 대체
  - 이미지: 자르기 영역, 테두리
  - 표: 셀 병합, 셀 채우기·테두리, 셀 텍스트
  - 그룹: 하위 요소를 그룹 좌표계로 배치
  - 배경과 레이아웃·마스터 요소(`layoutElements`)
- [x] 1차 미지원 요소는 자리 표시 상자로 그린다: 차트("차트"), SmartArt(내부 도형이 있으면 그리고 없으면 텍스트 목록), 수식(이미지가 있으면 이미지), 동영상·오디오("미디어").
- [x] 웹뷰가 표시하지 못하는 이미지 형식(EMF·WMF·WDP)은 깨진 아이콘 대신 "이미지 (EMF)" 같은 자리 표시로 그린다. 로컬 PPTX 이미지 중 EMF 591개(약 3%)로, 특정 자료에 몰려 있다(시각 확인 중 발견).
- [x] 한글 글꼴: 텍스트 HTML의 `font-family`를 작은따옴표로 감싸고 뒤에 `'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif`를 덧붙인다. 계획의 `@font-face local()` 별칭 대신, 설치된 글꼴의 여러 굵기를 그대로 쓰는 이 방식으로 바꿨다.
  - 리뷰에서 발견해 고침: 처음에는 대체 글꼴을 큰따옴표로 넣어 pptxtojson의 `style="…"` 속성이 끊기고 같은 속성의 굵기·색이 사라졌다. 작은따옴표로 바꾸고, 파싱한 스타일로 굵기·색이 남는지 테스트한다.
  - 표본 글꼴 이름에 `더잠실 2 Light`처럼 숫자로 시작하는 단어가 있다. 따옴표 없이는 CSS 문법 오류로 선언이 무시되므로 원래 이름도 따옴표로 감싼다.

### 3. 뷰어
- [x] PDF 뷰어의 구조(썸네일 목록, 현재 페이지, 도구 줄, 키 처리)를 `paged/PagedPreviewLayout`으로 분리하고 PDF·PPTX가 함께 쓴다. 분리 후 PDF 테스트가 그대로 통과했다.
- [x] 현재 슬라이드: 샌드박스 iframe 하나에 슬라이드 HTML을 넣고 창 크기에 맞춰 배율을 적용한다. iframe은 포커스·마우스 입력을 받지 않아 화살표 키를 가로채지 않는다.
- [x] 썸네일: 보이는 것만 작은 배율의 iframe으로 그리고, 목록 밖으로 벗어나면 해제한다(공통 레이아웃의 `releaseHiddenThumbnails`, PPTX만 사용). 수백 장 자료에서 ↓를 누르고 있어도 iframe 문서가 쌓이지 않게 하기 위해서다.
- [x] 100장 제한을 없앴다.
